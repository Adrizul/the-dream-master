# The Dream Master

A 2D point-and-click puzzle game made with Godot 4. It helps children (ages 9-12) practice reading comprehension: to move forward, the player reads clues, collects keywords in a journal and uses them to solve puzzles.

> Status: early prototype (v0.1). Academic project for a Computer Graphics course (TecNM Campus Chihuahua II).

## Concept
The player enters a child's dream and explores fixed scenes, like an escape room. The game never says "reading is good": reading is simply what lets you advance.

## Features (v0.1)
- Two scenes: tower exterior and tower interior
- Clickable objects: left click to interact, right click to read a description
- Highlighted keywords that are saved automatically in a journal
- Reusable text box and base scene
- One phrase-completion puzzle

## How to run
1. Install Godot 4 (made with 4.7.2).
2. Open Godot, click Import and select `Proyecto-Dream-Master/project.godot`.
3. Press F5 to play.
